# مكتبة الورّاق

واجهة متجر كتب عربية ثابتة باللغة العربية، مبنية باستخدام HTML وCSS وJavaScript خام، مع دعم اتجاه الكتابة من اليمين إلى اليسار وتصميم متجاوب للشاشات الصغيرة.

## التشغيل المحلي

لا يحتاج المشروع إلى تثبيت حزم أو إعداد خادم خلفي. يمكن تشغيله مباشرة من المجلد عبر:

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

ثم افتح `http://localhost:4173/` في المتصفح.

## الوظائف الحالية

يتضمن الموقع البحث في العناوين والمؤلفين، والتصفية حسب التصنيف، ونافذة تفاصيل الكتاب، وسلة مشتريات جانبية تدعم زيادة الكمية وإنقاصها والحذف، مع حفظ السلة في `localStorage`. كما يتضمن نموذج اشتراك تجريبي في النشرة الأسبوعية، وحركات ظهور عند التمرير، وتصميمًا متجاوبًا وإتاحة أساسية للوحة المفاتيح وقارئات الشاشة.

## ملاحظات مهمة

السلة والدفع والنشرة الحالية وظائف واجهة تجريبية فقط؛ لا يوجد خادم أو قاعدة بيانات أو بوابة دفع، ولا يتم إرسال الطلبات فعليًا. لإطلاق متجر حقيقي، يجب ربط هذه الواجهات بخدمة خلفية آمنة، وإضافة إدارة المنتجات والمخزون، وتكامل دفع، وتحقق من البريد، وسياسة خصوصية وشروط استخدام.

## ما تم إصلاحه في المراجعة

أزيلت نسخة HTML المكررة وحقن Cloudflare الخاص ببيئة الاستضافة السابقة، واستُبدل رابط البريد المحمي برابط `mailto` مباشر. أضيف عنصر `main` ورابط تجاوز للمحتوى، وصُحّحت معالجة نموذج النشرة حتى لا يعيد تحميل الصفحة، وأضيفت سلة فعلية بدل عدّاد شكلي، مع تخزين محلي وتحديث تلقائي للمجموع. كما حُسّن البحث العربي ليكون أكثر تسامحًا مع التشكيل وبعض اختلافات الحروف، وأضيفت حالة `inert` للعناصر المخفية لتحسين الوصول، ووُضعت جميع الأزرار ذات السلوك البرمجي على النوع `button` عند الحاجة.
